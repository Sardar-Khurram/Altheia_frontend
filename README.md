# Alethia - Fact Checker

A React-based fact-checking application powered by GPT-2 and Wikipedia verification.

## Getting Started

### Backend
```bash
cd backend
pip install -r requirements.txt
python app.py
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

## Features

- GPT-2 powered question answering
- Wikipedia fact verification
- Real-time similarity scoring
- Clean, intuitive interface
- Detailed claim analysis
